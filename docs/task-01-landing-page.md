# Tarea 1: Landing Page Simple

## Descripción
Creación de una landing page inicial y minimalista como punto de entrada para el proyecto "¿Quién Quiere Ser Lector?". En esta fase no se aplica una identidad visual definitiva, enfocándose en la estructura base.

## Propósito
- Reemplazar el código de plantilla por defecto de Next.js.
- Proveer la estructura inicial para conectar posteriormente el componente de subida de archivos PDF y la navegación al visor.

## Componentes y Cambios
1. **`src/app/layout.tsx`**:
   - Actualización de metadatos (`title` y `description`) acordes al proyecto.
2. **`src/app/page.tsx`**:
   - Título principal (`h1`): "¿Quién Quiere Ser Lector?"
   - Subtítulo (`p`): "Herramienta para leer libros con elementos de gamificación"
   - Botón: "Subir PDF" (no funcional por el momento).

# Tarea 71: Botón de GitHub en la Landing Page

## Descripción
Integración de un botón de enlace directo al repositorio oficial de GitHub del proyecto (`https://github.com/FelipeRomeroDUOC/CoderCup-Lecturama`):
1. **Ubicación**: Esquina superior derecha de la landing page (`absolute top-6 right-6`).
2. **Comportamiento**: Abre en una nueva pestaña (`target="_blank"`, `rel="noopener noreferrer"`).
3. **Estilo**: Botón estilo píldora con el isotipo oficial SVG de GitHub, hover responsivo y soporte para tema claro/oscuro.

## Propósito
- Permitir a los usuarios y evaluadores acceder directamente al código fuente y documentación del proyecto en GitHub.
